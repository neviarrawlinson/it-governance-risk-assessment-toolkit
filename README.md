# IT Governance Risk Assessment Toolkit

This toolkit helps IT, GRC, and security teams assess risk, evaluate control effectiveness, and organize governance efforts with simple, reusable templates.

It’s designed to be easy to understand, flexible enough for different use cases, and practical for day-to-day decision-making.

---

## What's Included

### 1. Risk Assessment Template
A spreadsheet for identifying, rating, and tracking risks. Includes columns for likelihood, impact, existing controls, and residual risk.

### 2. Control Checklist Template
A spreadsheet to evaluate the effectiveness of current controls. Helps track implementation status, control strength, and ownership.

### 3. Sample Dashboard
A visual summary (heatmap and control status chart) showing how risk and control data can be communicated to stakeholders.

### 4. Documentation
- [`docs/usage_guide.md`](docs/usage_guide.md)  
  Step-by-step instructions on how to use the toolkit  
- [`docs/example_use_case.md`](docs/example_use_case.md)  
  A sample scenario to illustrate how teams can apply the templates

---

## Use This Toolkit To

- Prepare for internal audits or certification readiness (SOC 2, ISO 27001, etc.)
- Document and prioritize IT risks
- Review and improve governance controls
- Present risk and control summaries to leadership

---

## Who This Is For

This toolkit is useful for:
- GRC Analysts  
- IT Governance teams  
- Risk and Compliance professionals  
- Security leaders  
- Project managers with risk responsibility

No prior tools or platforms required. Files are provided in Excel format and markdown.

---

## How to Use

1. Start with the Risk Assessment Template  
   Identify key risks, assign likelihood and impact scores, and document existing controls.

2. Evaluate Controls with the Checklist  
   Review your controls across systems and projects, and assess whether they’re effective.

3. Visualize Results  
   Use the dashboard image as inspiration, or build your own in Power BI or Excel.

4. Document and Review  
   Use the included guides or write your own internal SOP using these files as a baseline.
